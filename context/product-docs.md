# TaskFlow - Product Documentation

## Getting Started

### Creating Your First Project

1. Click "New Project" in the sidebar
2. Enter project name and description
3. Choose project template (optional)
4. Invite team members
5. Start adding tasks

### Adding Tasks

**Quick Add:** Press `Q` anywhere to open quick add dialog

**From Project View:**
1. Click "+ Add Task" button
2. Enter task title
3. Set assignee, due date, priority (optional)
4. Click "Create" or press Enter

**Task Fields:**
- Title (required)
- Description (supports Markdown)
- Assignee
- Due date
- Priority (Low, Medium, High, Urgent)
- Tags
- Custom fields
- Attachments

## Features

### Time Tracking

**Starting Timer:**
1. Click timer icon on any task
2. Timer runs in background
3. Stop when done

**Manual Entry:**
1. Click task → Time tab
2. Enter duration manually
3. Add notes (optional)

### Automation

**Creating Automation Rules:**
1. Go to Project Settings → Automation
2. Click "Create Rule"
3. Define trigger (e.g., "When task is completed")
4. Define action (e.g., "Move to Done column")
5. Save rule

### Collaboration Features

**Comments:**
- @mention team members
- Add attachments
- Edit/delete comments

**File Attachments:**
- Drag & drop files (up to 100MB)
- Supported formats: All common file types
- Preview images, PDFs directly

## Account Management

### User Roles

**Owner:** Full access, manage billing  
**Admin:** Manage team, create projects  
**Member:** Create tasks, collaborate  
**Guest:** Limited project access

### Billing

**Changing Plan:**
1. Settings → Billing
2. Click "Change Plan"
3. Select new plan

**Payment Methods:**
- Credit/debit cards
- ACH (Enterprise only)

## Troubleshooting

### Common Issues

**Cannot log in:**
- Reset password at login page
- Check email for reset link

**Tasks not syncing:**
- Refresh browser (Ctrl+R / Cmd+R)
- Check internet connection

**File upload failing:**
- File size limit: 100MB
- Try different browser

## FAQs

**Q: Can I use TaskFlow offline?**  
A: No, TaskFlow requires internet connection.

**Q: What's the maximum file size?**  
A: 100MB per file.

**Q: Is there a mobile app?**  
A: Yes. iOS and Android available.

**Q: How do I cancel my subscription?**  
A: Settings → Billing → Cancel Subscription.

**Q: Do you offer refunds?**  
A: 30-day money-back guarantee for annual plans.

**Q: Is my data secure?**  
A: Yes. 256-bit SSL, SOC 2 certified, GDPR compliant.
